HOW TO PARSE
- Treat this as a machine-readable prompt pack for KnightSlide sprites.
- There is one GLOBAL_STYLE. Each FILE block already includes it inside PROMPT. You may paste PROMPT as-is. If you rebuild a prompt, append GLOBAL_STYLE to every prompt.
- Do not translate PROMPT into Korean. Do not drop sentences. One prompt = one image.
- Save output as PNG using FILENAME exactly (lowercase, underscore).
- Blocks run from ===== FILE: name ===== to ===== END =====.
- Keep ALL files: ally T1-T10, all enemies, all backgrounds.

GLOBAL_STYLE

COMMON RULES
- ally T1-T10: player camera, STRICTLY FROM BEHIND, walking UP the screen, NO face, NO front view, full body, feet at bottom of frame, readable silhouette. Higher tier = bigger, flashier armor, cape, weapons. Same series look.
- enemy: STRICTLY FROM THE FRONT, marching TOWARD the viewer, face visible.
- bg: no units, no UI, no text. Opaque.
- ally/enemy: transparent background. bg: opaque.
- PNG only. Prefer real transparency for units. If a unit comes out front-facing, or wall has archers, regenerate with the same prompt.
