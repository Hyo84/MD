# MD — KnightSlide (중세 슬라이드 & 머지 디펜스)

유닛을 슬링샷처럼 당겨 발사하고, 같은 티어끼리 합쳐 더 강한 유닛을 만들어
위에서 몰려오는 몬스터를 막아내는 웹 게임 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 http://localhost:5173)로 접속하면 됩니다.

## 조작

- 화면 하단에서 탭/드래그로 가로 위치를 정하고 놓으면 유닛이 수직으로 발사됩니다.
- 같은 티어의 아군 유닛 두 개가 충돌하면 한 단계 높은 티어로 합쳐집니다.
- 적은 상단의 웨이브라인에 붙어서 라인 전체가 아래로 전진합니다.
  적이 많을수록 라인이 빨라지고, 교전 중인 아군의 저지력만큼 느려집니다(밀어내기 가능).
- 웨이브라인이 빨간 마지노선(Y=660)에 닿으면 게임 오버입니다.
- T9 두 개를 합치면 랜덤 영웅(아서 / 잔느 / 발키리)이 15초간 소환됩니다.
- **A 키** 또는 우측 상단 **⚙ 버튼**으로 어드민 패널을 열어 밸런스 수치를 실시간 수정할 수 있습니다.

## 기술

- Vite + Vanilla JS
- HTML5 Canvas 렌더링
- Matter.js 물리 엔진
